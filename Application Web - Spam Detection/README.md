Processus et Modèle :
  - Dataset : Téléchargement sur French Spam Torch Flaubert et triage pour garder ceux en français
  - Modèle : RNA à 2 couches cachées (fonction d'activation: relu) et une sortie (fonction d'activation : sigmoïd)

Méthodes ML :
  -Tokenisation : séparation de chaque mot.
  -Bag Of Words : trie des mots inutiles à la détection
  -Vectorisation : Transformation des mots en nombres pour les faire entrer dans le modèle
